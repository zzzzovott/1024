# 《第 1024 次搬家》当前实现:全流程逻辑与文本顺序

> 版本:白盒 Demo(第一人称)
> 说明:这份文档描述的是**当前代码里真实生效**的流程,不是设计稿。改完后发我,我按批注改代码/配置。
> 标记说明:🔧 = 可改 JSON 配置;📝 = 硬编码在代码里(建议一起迁进 JSON);⚙️ = Inspector 参数。

---

## 0. 一句话总览

单场景、第一人称。玩家抱着纸箱进入出租屋 → 放下箱子 → 把地上的旧物收进纸箱 → 找抹布擦桌子 → 发现铁皮青蛙/铁盒 → 三件旧物各解一个谜(得到密码 1/0/2)→ 擦合同得到 4 → 密码 1024 → 终局。

**操作**:WASD 移动 / 鼠标转视角 / Shift 跑 / Space 跳 / F 拾取·放下 / 左键 交互·拖拽 / 右键 放下手中物 / **Ctrl 呼出鼠标** / Esc 暂停。
**视角**:第一人称,准星固定在屏幕正中(白色圆环 + 中心点 + 黑色描边)。

## 9. 当前逻辑里需要你拍板的几个点

1. **开场是否要有"拿起箱子"这个动作?** 现在是开局就抱着。
2. **密码锁要不要手动输入 1024?** 现在集齐四位就自动判定通过,少了"输入密码"这一步。
3. **老电视**要不要并入流程/加台词?现在没文本、也不是主线。
4. **旧物解谜的记忆字幕**要不要也进 JSON?(目前写死在生成器里)
5. **引导文案**现在是 4 条固定句子按进度切,要不要改成"每一步一句 + 完成提示"?
6. **重复触发**:铁盒台词 6 秒冷却、没抹布提示 5 秒冷却、发呆提示 25 秒一次 —— 是否合适?
7. **顺序要求**:你给的文案表里,箱子 → 收纳 → 抹布 → 铁盒 → 光影,现在的逻辑**不强制**顺序(先擦灰再放箱子也可以)。要不要加顺序锁?

## 10. 改起来最方便的地方

| 想改什么 | 改哪里 |
|---|---|
| 任何台词/提示文本 | `Assets/Resources/Dialogue_1024.json`(保持 `id` 不变,只改 `text`) |
| 新增一句台词 | 在 JSON 里加一条 `{ "id": "...", "text": "..." }`,再告诉我要挂到哪个事件 |
| 距离/冷却/阈值 | 场景里对应组件的 Inspector(箱子 5 秒、灰尘 80%、旧物 2.5m、电视 2m 等) |
| 物体位置 | `Assets/Editor/GameSceneBuilder.cs` 里对应坐标,改完执行 `1024 → 重建场景(不弹确认)` |
| 整体流程顺序 | 需要改代码逻辑,批注在本文档上即可 |

> 场景是代码生成的:在 Unity 里手动改场景,下次"重建场景"会被覆盖。位置类改动请写在生成器里。
