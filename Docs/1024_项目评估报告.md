## 二、已有脚本清单(按职责)

**流程/全局**
- `GameFlowDirector`(471 行)— 流程大脑:Explore → Walking → FocusIn → Desk → Memory → FocusOut → Ending
- `CrosshairUI` — 准星(跟随鼠标的圆环,悬停变小手 + 文字)
- `InnerMonologue` — 内心 OS 打字机(逐字 + 键盘音 + 淡入淡出)
- `MemoryTransition` — 记忆穿梭白幕(白光过曝 + 耳鸣音 + 白幕最亮那一帧回调)
- `IntroSequence` — 序章开场(黑屏 → 撕胶带声 → 打字机 → 淡出)

**解谜**
- `DragRotateBody` — 拖拽旋转(阻尼 + 惯性 + 轴锁 + 吸附)
- `ShadowAlignPuzzle` — 单轴角度判定(8° 进入 / 11° 退出防抖 + 磁吸 + 进度驱动光斑)
- `SilhouetteMatchPuzzle` — 剪影像素重合度判定(IoU vs 数字模板)**代码存在但场景里未挂载**
- `SilhouetteProjection` / `SilhouetteProxy` — 正交"剪影相机"把旧物实时投到墙上 + 白色替身
- `CircularRewind` — 画圈倒带(atan2 + DeltaAngle 累加,3 圈 = 1080°)
- `ContractScratchUI` — 擦灰遮罩(UI 面板 alpha 擦除,42% 判定)

**终局/密码**
- `PasswordLockUI` — 四位密码锁(1024,弹入/错误抖动)
- `FinaleController` — 终局(暖光 + 便签打字机 +【打包带走】+ 截图生成"记忆凭证")
- `MoodLightingController` — 冷暖灯光 Preset 插值

**表现/工具**
- `Player25DController`(点击移动 + WASD)、`CameraStateRig`(房间/特写机位 + FOV 42↔30)
- `AudioDirector`(292 行,**程序化合成的全部音效**:点击/齿轮/底噪/打字/耳鸣/撕胶带/哼唱)
- `MemoryCuePlayer`(记忆碎片:环境音淡入 + 字幕)、`AudioVisualizer`(28 根频谱柱)、`RuntimeFont`(系统字体兜底中文)
- `SmokeTest`(`-smoke` 跑完整流程出报告)、`ScreenshotRunner`(`-shot` 自动截图)
- `Editor/GameSceneBuilder`(898 行,**一键重建整场景**,菜单 `1024/生成初稿场景`)、`WhiteBoxSceneBuilder`(319)、`DigitMaskFactory`(156)

## 六、与文档的四个结构性偏差(需要策划拍板)

1. **单场景 vs 多场景**:文档是"切场景 + 环境音渐入",实现是"同场景换机位 + 白幕"。要改回去,需要重做章节管理(Bridge/场景加载)与三套场景美术。
2. **准星位置**:中心白点 → 跟随鼠标。理由合理(2.5D 点击操作),但与文档不符。
3. **DOTween 全缺**:文档 9 个模块全部指定 DoTween,工程里 `manifest.json` 没有该依赖,全部用协程/SmoothDamp 手写。要么补依赖,要么改文档(否则后续按文档实现会引入两套动画体系)。
4. **解谜判定方式**:文档靠"角度误差 <3°/5°",实现改成"角度 + 磁吸"和"剪影像素 IoU(备选,未启用)"。白盒阶段更稳,但和文档数值不一致。

## 八、建议的下一步

1. **先定主工程**:明确 `1024move` 为唯一开发工程,把根工程的 `Mnostva_Art` 迁进去(或明确根工程只做美术试验,资产走导出)。
